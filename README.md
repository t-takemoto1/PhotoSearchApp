# PhotoSearchApp

iOS採用課題リポジトリ

## 概要
このリポジトリは、Pexels API を使って写真を検索・プレビューするシンプルな iOS アプリケーションの課題プロジェクトです。ユーザーはキーワードで写真を検索し、検索結果の一覧から写真を選択して全画面で閲覧できます。

## 前提条件
- Swift を用いて実装してください。
- 可能であれば RxSwift を利用してください（必須ではありません）。
- MVVM パターンの採用を推奨しますが、明確な設計意図を示せれば他のアーキテクチャでも構いません。
- ビルド環境は最新の Xcode を想定してください。

## ゴール
- ユーザーがキーワードを入力して写真を検索できること（検索フィールドを用意する）。
- API のレスポンスを写真プレビューのリスト（UITableView または UICollectionView）として表示する。
- 各リストのセルは写真と撮影者の名前を表示する。
- セルをタップすると写真を全画面で閲覧できる画面に遷移する。
- 最低限のエラーハンドリング（ネットワークエラー、検索結果0件など）を行うこと。
- ページネーションは任意です。

## 技術スタック
- 言語: Swift
- UI: UIKit 推奨（SwiftUI を使う場合は評価できない場合がある旨ご注意ください）
- 推奨ライブラリ: RxSwift（任意）、Alamofire 等のネットワーキングライブラリは使用可
- アーキテクチャ: MVVM 推奨

## 利用する API
本プロジェクトでは Pexels の Free Photo API を利用します。ドキュメント:
- Pexels API ドキュメント: https://www.pexels.com/api/documentation/
- Search API の説明に従って実装してください。

取得した API キーをアプリで利用してください（公開リポジトリに直接キーを含めないでください）。

### Pexels API の利用メモ
- リクエスト時にキーワードをクエリパラメーターとして渡してください。検索結果には写真のサムネイル URL と撮影者名が含まれます。
- レスポンスを解析して一覧表示用のモデルにマッピングしてください。

## 画面構成（例）
1. 検索画面（Photo Search）
   - 検索フィールド（キーワード入力）
   - 検索結果を表示する TableView / CollectionView
   - 各セルは写真のサムネイルと撮影者名を表示
2. 写真表示画面（Photo Detail）
   - 選択した写真を全画面で表示
   - 共有や保存などの操作は任意

## 実装ガイドライン
- シンプルで動作することを最優先にしてください。UI を過度に凝る必要はありませんが、整理され読みやすい UI を心がけてください。
- RxSwift を使用する場合は、プロジェクト内に簡単な利用例（Observable/Disposable の取り扱い等）を示してください。
- ネットワークエラーや0件ヒット時のハンドリングを最低限実装してください（エラーメッセージや空状態の表示など）。
- テストコードは任意ですが、書いた場合は評価対象となります。
- 外部ライブラリは使用可。ただし、サードパーティライブラリだけで全てを構築せず、コアロジックは自身で実装してください。
